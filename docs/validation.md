### 发现和修复

- JSON/schema 克隆会丢弃自有 `__proto__` 字段，改变制品身份；文件清单还会遗漏同名文件，并把已经完成的交付恢复误判为 blocked。现在校验后保留原键，构造清单和读取缺项均不经过原型属性；真实文件回归覆盖快照、冻结检查、采用、中断回滚与恢复。
- 领域评价保持开放 JSON 字段，核心不强制 score 为数字；异常补充检查不会清空其他真实失败。仅交付、无需方向内保留的候选仍可参与重排。
- 类型检查发现尚无评价的实验会触发空值读取；真实 Web 发现设置与改动区使用重复 React key，轮询时不断增加设置面板。两项均已修复，渲染回归检查连续更新。
- 评价依据重复进入不增加评价版本或观测；普通对象形式的后端异常保留原始 message。状态故障夹具从完整的当前记录构造，恢复断言保留。

注释按可核对的契约和原因复核，没有新增旧格式兼容层。本次未验证真实模型长程探索、Linux、macOS 与桌面分发。

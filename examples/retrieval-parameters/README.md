# 参数制品示例

将这个目录复制为工作区，选择“持续探索 · SLA”，发送：

> 根据已有检索评测集优化参数，先提高召回率，再减少返回条数，交付参数包。

`retrieval-eval.json` 是已有的英文词项检索数据集，`retrieval-params.json` 是初始参数。评测器在插件领域扩展中，运行开始时冻结数据集，不生成 `.sla` 脚本。Agent 只提出参数；Host 独立执行评测。

候选是版本化 JSON 对象。采用后在本次探索证据目录交付 `parameters.json`，原项目文件保持不变。这个小样例验证工作流接入、搜索接续与交付，不用于证明真实检索系统效果。
